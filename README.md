## Описание

Сервис по расчету графиков платежей:
1. График платежей заемщика по займу.
2. График выплат инвесторам, инвестировавшим в этот займ.

## Установка и запуск проекта

Установите окружение и необходимые пакеты:
```bash
$ docker compose up -d
$ npm install
```

Соберите проект:
```bash
$ npm run build
```

Запустите проект первый раз, чтобы создать таблицы в БД:
```bash
$ npm run start
```

Остановите работу ПО.

Импортируйте займы и инвестиции из json файла, который уже имеется в проекте:
```bash
$ npm run import-investments -- ./importData/investments_with_strategy_rate.json
```

Теперь ПО можно запускать и работать с ним
```bash
$ npm run start
```

Перейдите по указанной ссылке в браузере, чтобы увидеть график выплат займа и инвестиций:
http://localhost:3000/loan/00000000-0000-0000-0000-000000000000/schedule



## Полезные команды

```bash
# Сборка проекта
$ npm run build

# запуск проекта. При первом запуске создаст БД.
$ npm run start

# Импорт данных о займах и инвестициях из файла
$ npm run import-investments -- ./importData/investments_with_strategy_rate.json
```
